Connection & wiring
  1. Plug in an ESP32-S3 SuperMini with a USB data cable. Close other serial monitors.
  2. Install once, close the installer, then choose Connect USB and select the Espressif USB JTAG/serial port.
  3. Select three different GPIOs, set the pulse and auxiliary levels, then enable outputs. Changes to the pulse or aux levels apply immediately.
  4. Connect the device’s signal input to the PWM GPIO and use a shared ground. Supply loads from a suitable power source.

If flashing will not start, hold BOOT, tap RESET, release BOOT, and try again. Tap RESET after installation if needed.

Outputs switch off when you stop, disconnect, or hide this tab. If communication is lost, firmware disables outputs after 2 seconds. Disabled pins are high impedance.
